# Admin Dashboard

Tableau de bord d’administration responsive pour piloter les données de l’app.  
Mise en page construite principalement avec **CSS Grid**.

## Objectif

Donner une vue claire et rapide sur :
- Les métriques clés du jour/semaine/mois
- La gestion des utilisateurs, produits, commandes
- Les logs et l’activité récente
- Les actions admin : création, édition, suppression
